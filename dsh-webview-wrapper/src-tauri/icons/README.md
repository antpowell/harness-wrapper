# Icons

Place your application icons here:

- `32x32.png` - 32x32 pixel PNG icon
- `128x128.png` - 128x128 pixel PNG icon  
- `128x128@2x.png` - 256x256 pixel PNG icon (for high DPI)
- `icon.icns` - macOS icon format
- `icon.ico` - Windows icon format

You can generate these from a single source image using tools like:
- [tauri icon command](https://tauri.app/v1/guides/features/icons/): `npm run tauri icon /path/to/icon.png`
- Online converters

For now, you can copy placeholder icons or generate them from the DSH logo.
